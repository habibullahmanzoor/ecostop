# Manuscript folder

`main.tex` and `references.bib` here are the **earlier submitted version** of the manuscript
(title: *EcoStop: Certified Early Stopping for Energy-Efficient Training*). They are kept because the
`v1.0` tag and the rest of this repository describe that version.

The revised manuscript is titled *Early stopping, audited: curve extrapolation adds nothing, and the schedule decides*. Its source is not in this repository while it is under review;
the compiled version and its source will be added here on acceptance.

The benchmark data, the frozen protocols and the analysis code are unaffected by that revision. What
changed is the description of the findings, which the top-level README now states accurately: the
certificate must be stratified by declared schedule family rather than by domain, and the
learning-curve rule contributes nothing at matched risk.
